# javascript-racingcar-precourse

## 구현 기능
- [x] 입력
  - [x] 자동차 이름
  - [x] 시도할 횟수
- [x] 유효성 검사
  - [x] 자동차 이름 5자 이하
- [x] 자동차 이름 파싱
- [x] 게임 진행
  - [x] 각 차수 마다 무작위 값을 구함
  - [x] 무작위 값이 4 이상일 경우 전진
- [x] 출력
  - [x] 차수별 실행 결과
  - [x] 최종 우승자

## 프로그래밍 요구 사항
- [x] 들여쓰기 depth <= 2
- [x] 3항 연산자 사용 금지
- [x] 함수 최대한 작게 만들기
- [ ] Jest로 테스트 코드 작성
